# Programming Fundamentals

A collection of beginner-level programming exercises developed using **C#**. This repository focuses on fundamental programming concepts, mathematical operations, random number generation, conditional statements, loops, and basic algorithms.

## Projects

### 1. 3Dices
Simulates rolling three six-sided dice 100,000 times and calculates the frequency of each possible sum (from 3 to 18).

**Concepts:** Random Number Generation, Arrays/Lists, For Loops, Frequency Counting.

### 2. 100 Dices
Simulates rolling a six-sided die 100 times and prints the result of each roll individually.

**Concepts:** Random Number Generation, For Loops, Console Output.

### 3. Dice Program
Simulates rolling two six-sided dice 100,000 times and counts how often each possible sum (from 2 to 12) occurs.

**Concepts:** Random Number Generation, Conditional Statements, Loops, Counters, Probability.

### 4. Factorial
Calculates the factorial of a given number using a for loop. The current example calculates 6! (6 factorial).

**Concepts:** For Loops, Variables, Mathematical Operations.

### 5. Prime Numbers
Checks whether numbers are prime, lists prime numbers between 1 and 200, and counts the number of primes within different ranges (1–100, 101–200, and 1–100,000).

**Concepts:** Methods, Boolean Logic, While Loops, For Loops, Conditional Statements, Modulo Operator.

### 6. Secret Number
A number guessing game in which the player tries to guess a randomly generated number between 1 and 100. The program provides hints indicating whether the guess is too high or too low.

**Concepts:** Random Number Generation, While Loops, User Input, Conditional Statements.

### 7. Triangle
Generates three random side lengths and checks whether they satisfy the triangle inequality theorem. Determines whether the given sides can form a valid triangle.

**Concepts:** Random Number Generation, Conditional Statements, Logical Operators, Mathematical Conditions.

## Purpose

The purpose of this repository is to practice fundamental C# programming concepts, improve problem-solving skills, and build a foundation in software development through small exercises and simulations.
